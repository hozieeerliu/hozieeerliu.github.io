# hozierliu.com

Quarto website source for a personal academic site. The homepage uses the currently selected abstract jade mountain artwork at `assets/images/home-mountain.png`.

## Preview

From this folder, run `quarto preview`.

## Build

Run `quarto render` to generate the static site in `_site/`.

Notes about content:
- Research is intentionally an empty first draft.
- Notes, projects and writing contain lightweight structural placeholders until the existing material is migrated.
- The project does not publish or change the live WordPress site.
